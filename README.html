Open the generated results report · Read the downloaded paper

This is a public-data reconstruction, not an exact numerical replication. The authors’ original data/code and historical input vintages were not supplied. Public observations are used without synthetic fillers. Read the data provenance and limitations in the results report before interpreting any agreement or disagreement.

Run on this Windows machine

The required Python packages were already installed and are pinned in requirements.txt. These commands run from the replication directory. No server or browser installation is needed.

Set-Location -LiteralPath 'C:\Copilot Code Test\Danov et al replication'
$env:PYTHONDONTWRITEBYTECODE = '1'
$env:OPENBLAS_NUM_THREADS = '1'
$env:OMP_NUM_THREADS = '1'
$env:PYTHONIOENCODING = 'utf-8'
python -B -m unittest test_replication -v
python -B replicate.py
python -B validate_results.py

The full command runs one-, two-, and three-factor models, all 103 twice-monthly forecast dates, release-news attribution, accuracy metrics, annual GDP aggregation, figures and the HTML report. Actual date and row counts are recorded in results\run_configuration.json. Running from the saved normalized observations requires no network access.

# Rebuild normalized data from saved source files (no new downloads):
python -B download_data.py
# Explicitly refresh the source files; revised websites/data may change results:
python -B download_data.py --refresh
# Rebuild only the report and figures from saved results:
python -B reporting.py
# Optional reduced run; not the full reconstruction:
python -B replicate.py --factors 2 --maxiter 500

Do not run package installation unless dependencies are actually missing. In a separate clean environment, use the pinned requirements file. Do not weaken Windows file protections to run this project.

Model and timing choices

  • Paper Sections 2 and 3 and Annex B define the model. Indicators use 100 times the 12-month log difference; GDP uses the four-quarter log difference. PMI and visitor arrivals remain in levels. There is no seasonal adjustment or winsorization beyond the paper’s transformations. Zero or negative logged levels become missing and are counted in coverage diagnostics.
  • Monthly states include jointly estimated VAR(1) common factors and mutually uncorrelated AR(1) idiosyncratic components. Quarterly GDP is observed only at quarter ends, loading on the sum of the current and preceding two monthly factors and GDP-specific components. Five lag slots are retained internally for compatibility with statsmodels, but the last two observation weights are zero.
  • Statsmodels normally uses the five-term [1,2,3,2,1] aggregation for quarter-on-quarter growth. The custom subclass replaces both the observation equation and the missing-data EM loading update with the paper’s [1,1,1] year-on-year rule; changing only the design matrix would be incorrect.
  • GDP growth here means 100 log(GDPq/GDPq−4). It is not four times quarter-on-quarter growth. The text of the paper sometimes says “annualized,” and Section 3.2’s monthly-growth description differs from Annex B; the implementation follows the explicit Annex B year-on-year restriction.
  • The initial fit uses the available data on September 21, 2021, over January 2010–August 2021. Subsequent fits use the information set on the first day of each quarter, up to the previous month, and at most twelve years. PCA initialization is recalculated within each training vintage. Standardization and parameters are fixed during each quarter. No hyperparameters are selected using out-of-sample accuracy.
  • Forecast origins are the 7th and 21st, September 21, 2021 through December 21, 2025. Each origin produces current-quarter and previous-quarter predictions. Fixed Table 1 lags are applied to each observation’s period end. This is an explicit approximation to actual publication dates, not the Haver calendar.
  • Backcasts use the conditional smoothed state given the complete origin-specific vintage; using one-step-ahead fitted values would incorrectly ignore indicators released after the target quarter. State uncertainty is propagated to the displayed conditional 95% intervals.
  • News contributions compare two vintages under identical parameters, standardization, sample start and state initialization. At quarter boundaries the change due to reestimation, rescaling and rolling-window changes is reported separately from release news. First-origin change fields are zero because no preceding forecast is compared.
  • Calendar-year GDP growth is reconstructed from sums of quarterly levels. Unreleased quarters use the model’s log year-on-year prediction times the known or recursively predicted corresponding prior-year quarter. Released quarterly levels enter directly. Annual growth is not the unweighted average of quarterly growth rates.
  • Benchmarks are last released GDP growth, expanding historical mean and an expanding quarterly AR(1) regression. They use only lag-eligible GDP at the origin. AR slopes are clipped to ±0.99 for long-horizon stability. Their performance is not a substitute for the authors’ dated CBK and WEO comparisons.

What is and is not reproduced

The package reconstructs Table 1-style descriptive quantities, the Figure 3 common-component exercise, dated quarterly paths, release news, forecast errors and annual predictions, with one- and three-factor robustness variants. SVGs are new plots of independently reconstructed results, not copies of the paper’s artwork. The source vintage, missing-series list and numerical diagnostics are saved.

It does not assert reproduction of the exact authors’ figures, actual real-time performance after April 2024, first-release GDP errors, exact Haver release dates, or the institutional forecast-vintage comparison. If original source data become available, replace the normalized input observations while preserving provenance, then rerun. Historical revisions require actual dated vintages and additional ingestion logic; replacing a single final-vintage CSV does not create them.

Public-data substitutions and unresolved gaps

The executed panel contains ten monthly indicators plus quarterly GDP (eleven of the paper’s twelve total series). PMI is omitted. Arrivals consistently sum JKIA and MIA; other border crossings are excluded, including in newer files. Electricity is domestic generation, excluding imports. The GDP series uses the 2021 rebasing report for 2009–2019 and the December 2025 quarterly release thereafter, all at constant 2016 prices.

Three July–September 2009 electricity rows have apparent 2010 date labels in the 2009 report. They are excluded rather than silently corrected, so corresponding 2010 log differences are also missing. October 2010 airport arrivals are unavailable in the saved December editions and remain missing. Two trade gaps in March/April 2012 are filled with explicitly verified official KNBS values, not interpolated. See source-quality issues and the source/detail columns in the normalized observations.

Numerical diagnostics

EM has a configurable cap of 500 iterations and relative likelihood tolerance 10−5. Iteration histories and nonconvergence flags are retained. The package does not silently discard failed fits or substitute observed targets. News attribution is checked at every forecast comparison to within 10−6 percentage points. All forecast errors are measured against the acquired GDP vintage and only for completed target quarters.

Descriptive contemporaneous correlations use quarterly averages of transformed monthly indicators paired with quarterly GDP over 2010Q1–2021Q3. This aggregation choice is explicit because the paper does not fully specify the table calculation. Common variance ratios use the initial training sample. Full-vintage smoothed components shown descriptively are never fed into rolling forecasts.
